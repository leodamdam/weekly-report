# BTN설법학교 대웅전 신축 계획(안) — 기획설계 도면 패키지

건축사무소에 설계를 의뢰할 때 함께 보내는 **발주자 기획안**입니다.
시공 도면이 아닙니다. 구조, 법규, 인허가, 실시설계는 건축사무소가 맡습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `BTN설법학교_대웅전_계획도면.pdf` | A3 가로 8매 (출력·메일 송부용) |
| `dxf/*.dxf` | 도면별 CAD 파일 (단위 mm, 레이어 정리) |
| `make_drawings.py` | 도면 생성 스크립트. 상단 '설계 변수'를 고치면 모든 도면에 반영 |

### 도면 목록
- A-000 표지 · 설계개요 · 기획 의도
- A-001 배치도(개념) 1:400
- A-101 평면도 1:100
- A-102 방송·조명 설비 계획도 1:100
- A-201 정면도 1:100 (현판 「BTN설법학교」)
- A-202 측면도 1:100
- A-301 횡단면도 1:100
- A-901 설계의뢰 체크리스트

## 계획 요약
- 정면 5칸 × 측면 4칸, 팔작지붕, 다포식 공포, 장대석 기단 0.9m
- 주칸: 정면 3.6+4.2+4.8+4.2+3.6 = 20.4m / 측면 3.0+4.2+4.2+3.0 = 14.4m
- 바닥면적 293.76㎡(약 88.9평), 최고높이 약 12.6m
- 좌식 약 124석 (의자 배치 시 약 74석)
- 방송 녹화를 고려한 설계: 감주법으로 어칸 내고주를 빼서 정면 카메라 축 확보, 반자 속 조명 배턴 3열,
  마루 밑 배선, 후면 중계연결반, 중계차 외부 접속

## DXF 레이어
`A-GRID` 그리드 · `A-CUT` 절단선 · `A-OBJ` 외형선 · `A-THIN` 가는선 · `A-HID` 숨은선 · `A-DIM` 치수 ·
`A-TEXT` 문자 · `A-FURN` 불단·집기 · `A-GRND` 지반선 · `B-BRDC` 방송설비 · `B-BRDH` 방송배선 · `B-LGHT` 방송조명

문자 스타일 `KR`은 맑은 고딕(malgun.ttf)을 쓰도록 지정되어 있습니다.

## 다시 생성하기
```bash
pip install reportlab ezdxf
python3 make_drawings.py
```
